# Pluto Keyboard 0.6.2

**New to Pluto?** Install the APK below, then get the voice and correction models from the [models page](https://github.com/ColinCPittman/Pluto-Keyboard/releases/tag/models), which explains which files to pick and how to set them up. The [README](https://github.com/ColinCPittman/Pluto-Keyboard#readme) has the full story.

A fix-up release for voice typing and the settings screens.

## What's new

- **No more doubled dictations.** After you stop talking, Pluto takes a second or two to tidy up what you said. If you moved the cursor during that time (to fix a typo, say), the finished text used to be typed again where your cursor was. Now it replaces the words you saw while you spoke, right where you dictated them, and your cursor stays where you put it. If you changed those words in the meantime, they're left as you made them.
- **Keep the microphone to yourself.** A new switch on the Voice Input page, on by default. While you dictate, no other app can listen to the microphone. Turn it off if a screen recorder or call recorder needs to keep hearing you while you dictate.
- **Quicker settings.** The emoji names page no longer freezes for a few seconds when it opens with a long list of your changes. And on a slower phone, settings pages no longer show on top of each other for a moment while the next one opens.

## Models

No model has changed. Nothing new to download.

## Install

Install `pluto-keyboard-0.6.2.apk` over your old version (no need to uninstall), or let Obtainium do it. All your settings, learned words and models carry over.

`SHA256SUMS.txt` has the checksum if you want to verify the download.
